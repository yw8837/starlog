> 감사 스킬의 🔴/🟡는 규칙 기준 심각도, P는 사용자 영향 기준 우선순위라 둘이 다를 수 있음.

## 바로 할 수 있는 3가지

1. `--fs-sub: 13px` → `14px` (C-01)
2. 날짜 셀렉트 빈 값 표시 짧게 / 오른쪽 여백 줄이기 (C-03)
3. /me "문의하기"를 이메일 mailto로, /pricing 카드에 "타로 보기 →", "사주 보기 →" (T-14, W-06)

## 이미 잘하고 있는 것

- **접근성 기본기**
  - 모든 컨트롤에 금색 포커스 링이 있고, `aria-current`와 메뉴별 `nav` 이름이 들어가 있음
  - 32개 캡처 모두 가로 넘침 0
  - alt 없는 이미지 0
  - 동작 줄이기 설정을 켜면 애니메이션 0개로 실제 동작함
- **글자 대비**: 9–17:1 수준
  - 본문 16.7:1, 보조 글자 9.4–11.3:1, 금색 11.9–14.3:1
- **한글 타이포그래피**
  - 제목 Gowun Batang, 본문 Noto Sans KR 2서체 체계
  - `keep-all`, `text-wrap: balance` 적용
  - 가이드 본문이 종이 표면에 17px, 행간 1.8이라 가장 읽기 편함
- **채워진 시상대**: 은·금·동 단상과 메달, 별자리 배경. "프리미엄 밤하늘" 인상을 가장 잘 살린 화면
- **홈 첫 화면**: 375 첫 화면 안에 히어로, 타로·사주, 무료 타일 두 개가 다 보이고 캐릭터 역할이 바로 읽힘
- **윤리 설계**
  - 위기 상담 연락처, 행운 번호 확률 면책, AI 작성 고지
  - 동의 체크박스 기본값 해제
  - 실제 남은 횟수 표시
  - 삭제 확인창에 지워지는 내용 명시
