# 별자리 인연 · 행운 번호 · 이미지 공유 설계 (P3)

작성 2026-09-30, 같은 날 오너 피드백 반영. 오너가 정한 방향: 채울 별자리는 주인이 처음에 고르고 친구가 그 별자리에 차곡차곡 쌓이며, 다 채우면 별자리 그림 카드로 도감에 넣고, 인연(궁합) 점수 합계로 **전체 사용자 별자리 랭킹**을 만든다("별건 없고 자랑용·공유용"). 점수가 마음에 안 들면 완성한 별자리를 `새로 채우기` 할 수 있다. 친구는 생년월일을 꼭 넣는다.

이 문서는 기본 설계서 `2026-09-29-saju-tarot-story-app-design.md`의 §9(친구 참여 루프)를 대체한다. §9의 "순위를 쓰지 않는다"는 원칙은 오너 결정(2026-09-30)으로 바뀐다. 순위는 별자리마다, 닉네임만, 끌 수 있게 둔다. "친구 장면"은 이 기능의 "별"로 합친다.

순서: P2(진짜 풀이, 심사용 핵심)를 먼저 내보낸 뒤 시작한다. P3a는 별자리 인연, P3b는 행운 번호와 이미지 공유다.

## 1. 용어

- **별자리 인연**: 이 기능 전체의 이름. 메뉴 이름도 같다.
- **별**: 내 링크로 들어온 친구 한 명. 닉네임, 한 줄(선택), 친구가 고른 카드 한 장, 인연 점수를 가진다.
- **별자리**: 황도 12궁. 별 칸 수가 정해져 있다. 칸이 다 차면 완성된다.
- **도감**: 완성한 별자리 카드 모음. 12칸이다.
- **인연 점수**: 나와 친구의 사주 궁합 점수. 55~99점이다.
- **별자리 랭킹**: 같은 별자리를 완성한 사용자끼리 인연 점수 합계로 매긴 순위. 표기 예: `양자리 1등 인연 412점 - 용우`. 여기서 이름은 별자리 주인의 닉네임이다.

## 2. 별자리 고르기

어떤 별자리를 채울지는 **주인이 처음에 고른다**(오너 결정). 한 번에 하나만 채운다. 친구는 고른 별자리의 다음 칸에 들어온 순서대로 차곡차곡 쌓인다. 완성하면 아직 완성하지 않은 별자리 중에서 다음 것을 고른다. 고르는 화면에는 내 태양 별자리(생일 기준)에 `내 별자리` 표시를 붙여 첫 선택으로 권한다. 고른 별자리를 다 채워야 다른 별자리를 고를 수 있다. 중간에 `별자리 바꾸기`를 하면 **처음부터** 시작한다: 확인 창("지금 모은 별 N개가 사라지고 새 별자리를 처음부터 채워요")을 거쳐 그 별자리의 별이 모두 비워지고, 새 별자리를 고른다. 아래 표의 번호는 도감에 놓이는 순서(황도 순)일 뿐, 채우는 순서가 아니다.

|---|---|---|
| 1 | 양자리 | 4 |
| 2 | 황소자리 | 5 |
| 3 | 쌍둥이자리 | 6 |
| 4 | 게자리 | 5 |

합계는 67칸이다. 모양은 실제 별자리의 주요 별을 이 칸 수로 줄인 선화다. 12개 선화는 직접 그린 SVG로 만든다: 별 좌표, 별을 잇는 선, 오너 참고 이미지처럼 은은하게 빛나는 그림 윤곽선.

## 3. 흐름

### 주인(나)

1. `별자리 인연`을 처음 열면 닉네임을 정한다. 랭킹에 쓰이는 이름이라 실명 대신 별명을 권한다. 사주 프로필이 없으면 생년월일을 먼저 넣는다(시간은 선택).
2. 채울 별자리를 고른다(12궁 그림 중 하나, 완성한 것은 제외).
3. **초대코드**를 만든다. 주인마다 하나이고, 6자리 영문·숫자다. 헷갈리는 글자(0·O·1·I·L)는 빼고 대소문자는 구분하지 않는다. 예: `K7M4QX`. 링크(`/b/K7M4QX`)와 코드가 한 쌍이다.
   - 링크로 들어오든 코드를 입력하든, 그 친구는 **내가 지금 채우는 별자리**의 다음 별로 들어간다.
   - `코드 새로 만들기`를 하면 옛 코드와 링크는 바로 막힌다. 모르는 사람에게 퍼졌을 때 쓴다.
   - 공유 문구 예: "내 양자리에 별이 되어 줘 (0/4) · 초대코드 K7M4QX". 링크를 누를 수 없는 곳(인스타 스토리, 말로 전할 때)에서는 코드를 쓴다.
4. 친구가 들어오면 다음 칸이 켜진다. 들어온 순서대로 쌓이며, 점수는 칸 순서에 영향을 주지 않는다.
5. 마지막 칸이 차면 완성이다. 별자리 카드가 도감에 들어가고 랭킹에 오른다. 이어서 다음에 채울 별자리를 고른다.
6. 한 화면에서 쭉 읽힌다(오너 요청: 탭 없이 스크롤). 순서는 이렇다.
   - 지금 별자리의 진행 상황과 별 목록(닉네임, 카드, 한 줄, 점수, 점수 근거)
   - 초대 공유 버튼
   - 도감(황도 12궁): 칸을 누르면 **그 별자리의 랭킹 화면으로 바로 간다**(§6)
   - 내 인연 TOP 5

### 친구(가입 없음)

1. 링크를 열거나, 스타로그의 `초대코드로 참여` 칸(홈과 `별자리 인연` 화면, `/b`)에 코드를 넣는다. 문구는 "○○님의 양자리에 별이 되어 주세요"이고, 진행도(2/4)와 별자리 그림이 함께 나온다. 이미 스타로그를 쓰는 사람도 코드로 친구 별자리에 참여할 수 있다.
   - 주인이 아직 별자리를 고르지 않았거나 방금 완성해서 다음 별자리를 고르기 전이면 이렇게 안내한다: "○○님이 다음 별자리를 고르는 중이에요. 조금 뒤에 다시 와 주세요".
2. 입력은 닉네임 → 생년월일(필수, 시간은 선택) → 카드 한 장 고르기(셔플 고양이 포함) → 한 줄 남기기(선택, 40자) 순서다. 닉네임 칸 아래에 "○○님이 별자리를 공유하면 이 닉네임이 이미지에 보여요"를 적는다.
3. 결과로 인연 점수와 점수 근거, 짧은 궁합 풀이(근거로 만든 문장, AI 비용 없음)가 나온다. 친구 자신의 **오늘의 한 장**도 무료로 받는다(P2 daily 엔드포인트).
4. 끝에 `나도 내 별자리 만들기` 버튼이 있다.
5. 친구의 생년월일은 **점수 계산에만 쓰고 저장하지 않는다.**

## 4. 인연 점수 (결정적이고 설명 가능하게)

**같은 두 사람은 언제나 같은 점수**다(오너 확인). 무작위 요소가 없고, 친구가 고른 카드나 참여한 날짜는 점수에 들어가지 않는다. 누가 초대했는지와도 상관없이 A와 B의 점수는 B와 A의 점수와 같다. 그래서 `새로 채우기`로 점수를 바꾸려면 다른 친구를 채워야 한다. 두 사람 모두 **날짜만으로** 명식을 계산한다(`computeChart`, 기둥 3개). 태어난 시간을 넣어도 점수에는 쓰지 않는다. 시간이 오행 개수를 바꿔 같은 사람의 점수가 달라지는 일을 막기 위해서다. 계산에는 일간 천간과 오행, 연지(띠), 일지, 오행 개수를 쓴다.

| 항목 | 조건 | 점수 |
|---|---|---|
| 기본 | | 62 |
| 일간 | 천간합(甲己·乙庚·丙辛·丁壬·戊癸) | +12 |
| | 그렇지 않고 오행 상생(어느 방향이든) | +10 |
| | 그렇지 않고 같은 오행 | +6 |
| 띠(연지) | 육합(子丑·寅亥·卯戌·辰酉·巳申·午未) | +8 |
| | 삼합 같은 무리(申子辰·寅午戌·巳酉丑·亥卯未) | +7 |
| | 같은 띠 | +4 |
| | 충(子午·丑未·寅申·卯酉·辰戌·巳亥) | −5 |
| | 원진(子未·丑午·寅酉·卯申·辰亥·巳戌) | −3 |
| 일지 | 육합 +6, 삼합 무리 +5, 충 −4 | |
| 오행 보완 | 내가 가장 적게 가진 오행을 친구가 2개 이상 가짐 | +5 |
| | 친구가 가장 적게 가진 오행을 내가 2개 이상 가짐 | +5 |

- 띠와 일지는 해당하는 항목 가운데 가장 큰 것 하나만 센다.
- 최종 점수는 55~99점으로 자른다. 이론상 최고는 98점, 최저는 53점이다.
- 점수 근거는 쉬운 말로 보여준다. 예: "두 분의 일간이 서로 살려 주는 사이예요 +10", "띠가 짝을 이루는 사이예요 +8".
- 문구 규칙:
  - 충이나 원진이 있어도 겁주는 말은 쓰지 않는다. 예: "부딪히면서 서로를 깨우는 사이예요".
  - 단정도 하지 않는다. "명리에서는 ~로 읽어요" 식으로 쓴다.
  - 연애나 결혼으로 단정하지 않는다. 친구 관계에 두루 맞는 말을 쓴다.
- 입춘이나 절입일 근처에 태어나 연주·월주가 모호한 경우에는 경고를 따라, 두 후보 중 기본 정책값을 쓰고 근거에 "태어난 시각에 따라 달라질 수 있어요"를 붙인다.
- 주인의 궁합 기준값(일간, 연지, 일지, 오행 개수)은 서버에 저장한다. 친구가 들어올 때 주인은 접속해 있지 않기 때문이다. 주인의 생년월일 자체는 저장하지 않는다.

## 5. 완성, 도감, 공유 이미지

- 완성 순간 연출: 별이 차례로 켜지고 선이 이어진 뒤 그림이 떠오른다. 고양이와 토끼가 축하한다. 움직임 줄이기 설정이면 연출 없이 바로 보여준다.
- **도감**은 황도 순서의 12칸이다. 완성한 칸은 선화가 빛나고, 채우는 중인 칸은 진행도(2/4), 아직 안 고른 칸은 흐린 실루엣이다. 어느 칸이든 누르면 그 별자리의 **랭킹 화면**(§6)으로 간다.
- **별자리 공유 이미지**(내 완성 별자리, 1080×1350 PNG와 스토리용 1080×1920, 서버에서 `next/og`)에는 다음이 들어간다(오너 결정: 별자리에 있는 친구들이 잘 보이게).
  - 별자리 선화
  - **각 별 위치에 친구 닉네임**: 큰 글씨와 라벨 배경으로 선화 위에서도 또렷하게, 겹치면 라벨 위치를 자동으로 비킨다
  - 별자리 이름(양자리 · Aries), 인연 합계 점수, 주인 닉네임, 완성 날짜, 사이트 주소
  - 친구의 점수, 한 줄, 생년월일은 넣지 않는다
- 공유는 랭킹 화면의 내 카드와 주인 화면의 완성 카드에서 한다(§9 공유 방식).

## 6. 별자리 랭킹 (전체 사용자)

- 화면은 별자리마다 하나(`/ranking/[sign]`)이고 한 스크롤로 읽힌다. 맨 위가 내 카드다. 완성했으면 공유 이미지 미리보기와 순위, 그리고 버튼 두 개 `공유하기`·`새로 채우기`를 보여준다(오너 결정). 채우는 중이면 진행도와 초대 버튼을, 아직 안 골랐으면 `이 별자리 채우기` 버튼을 보여준다. 그 아래가 이번 주 랭킹, 명예의 전당이다.
- 별자리마다 따로 매긴다. 별 칸 수가 달라서 같은 별자리끼리만 비교한다.
- 점수는 완성한 별자리의 인연 점수 합계다. 동점이면 먼저 완성한 사람이 앞선다.
- 랭킹은 두 가지다.
  - **이번 주 랭킹**: KST 월요일 0시부터 일요일까지 완성한 것만. 매주 새로 시작해서 다시 올 이유가 된다.
  - **명예의 전당**: 전체 기간 대상.
- 보여주는 범위는 상위 50명과 내 순위다. 표기는 `양자리 1등 인연 412점 - 용우`, 내 순위는 `내 양자리 17등 · 인연 356점`으로 쓴다.
- 공개되는 것은 닉네임, 별자리, 점수, 완성 날짜뿐이다. `랭킹에 내 이름 올리기` 설정은 기본 켜짐이고 끌 수 있다. 끄면 순위에서 빠지고 "비공개"로도 표시하지 않는다.
- 닉네임은 2~10자이고 금칙어 필터를 거친다.

## 7. 새로 채우기

- 완성한 별자리 카드에는 `공유하기`와 `새로 채우기` 두 버튼만 둔다. 도감 칸을 눌러 들어가는 랭킹 화면의 내 카드와 주인 화면의 완성 카드가 같다.
- `새로 채우기`를 누르면 그 별자리를 **0칸부터 다시** 채운다. 확인 창을 한 번 거친다.
  - 기본 문구: "양자리 카드와 랭킹 기록(412점)이 사라지고 처음부터 다시 채워요".
  - 다른 별자리를 채우는 중이면 한 번에 하나만 채우는 규칙(§2)에 따라 그 별자리의 별도 사라진다. 이때 문구에 덧붙인다: "채우던 황소자리 별 2개도 사라져요".
- 새로 채운 결과는 새 기록이 된다. 완성하면 다시 도감에 들어가고 랭킹에 오른다.
- 친구에게는 알리지 않는다. 사라진 별의 친구가 링크나 코드로 다시 들어오면 새 칸으로 참여할 수 있다.
- 진행 중인 별자리를 바꾸는 것(§2)은 횟수 제한 없이 확인 창만 거친다. 아래 비용은 완성한 별자리를 `새로 채우기` 할 때만 든다.
- 비용(`새로 채우기`)
  - 베타: 무료지만 한 시간에 한 번만 된다.
  - 재화가 열린 뒤: 주 1회 무료, 그다음부터 별조각 5개.
- 주인은 별 하나를 지울 수도 있다(부적절한 한 줄 대비). 지우면 그 칸이 비고, 완성된 별자리였다면 미완성으로 돌아간다.

## 8. 행운 번호 (P3b)

- 이름은 "이번 주 행운 번호"다. "로또"라는 말이나 상표는 쓰지 않는다. 1~45 사이 번호 6개를 주고, 무료다.
- 주 단위다(KST 월요일 기준). 같은 사람이면 같은 주에는 같은 번호가 나온다. 사주 프로필이 필요하다.
- 규칙(설명 가능하게)
  1. 오행과 숫자는 전통 대응(하도수)을 쓴다. 水 1·6, 火 2·7, 木 3·8, 金 4·9, 土 5·10이다. 해당 끝자리를 가진 1~45 번호 묶음이 그 오행의 번호다.
  2. 내가 가장 적게 가진 오행의 번호 묶음에서 2개, 일간 오행의 번호 묶음에서 1개를 고른다.
  3. 이번 주 카드 한 장(주 단위로 서버에서 고정)의 번호에서 1개를 고른다. 메이저는 번호, 마이너는 숫자와 수트를 45 이내로 바꾼다.
  4. 나머지 2개는 이번 주 간지에 맞는 오행 묶음에서 고른다.
  5. 선택은 (사용자, 주) 시드로 돌리는 결정적 난수다. 중복은 없고 오름차순으로 보여준다.
- 번호마다 "왜 이 번호인지"를 한 줄로 붙인다. 예: "7 · 부족한 火를 채우는 숫자".
- 고지는 화면과 이미지 모두에 넣는다. 문구: "재미로 보는 번호예요. 추첨에서는 모든 번호의 확률이 같아요." 당첨이나 확률을 올려 준다는 표현은 금지한다.
- 공유 이미지를 만들 수 있다(§9).

## 9. 이미지 공유 (P3b)

- 공유 이미지 종류는 오늘의 한 장, 챕터 제목 카드(질문 없이 제목과 카드 3장), 별자리 공유 이미지(§5, 친구 닉네임 포함), 행운 번호, 친구 초대 링크의 OG 카드(1200×630, "○○님의 양자리 2/4")다.
- 인스타 스토리 크기는 1080×1920이다.
- 저장과 공유: 기기가 파일 공유를 지원하면 `navigator.share({files})`로 보내고, 아니면 이미지를 저장하고 링크를 복사한다.
- 이미지에는 질문, 메모, 출생정보를 절대 넣지 않는다.

## 10. 데이터와 개인정보

- 저장소는 Cloudflare D1(`DB` 바인딩)이다. 주인 식별은 로그인 전이면 기기 쿠키(`sl_uid`, 서명)로 한다. 화면에 "이 기기에서 이어져요. 로그인하면 다른 기기에서도 볼 수 있어요"를 안내한다.
- 테이블
  - `owners(id, nickname, ranking_public, basis_json, created_at)`: basis는 궁합 기준값이다(일간, 연지, 일지, 오행 개수).
  - `invites(code, owner_id, created_at, revoked_at)`: code는 고유하다. 새로 만들면 기존 행에 revoked_at을 기록한다.
  - `constellations(id, owner_id, sign, round, status, total, completed_at)`
  - `stars(id, constellation_id, slot, nickname, message, card_id, orientation, score, breakdown_json, friend_key, created_at)`: friend_key는 친구 기기 쿠키의 해시이고 중복 참여를 막는 데 쓴다.
- 저장하지 않는 것: 친구 생년월일, 주인 생년월일, 질문과 메모.
- 개인정보처리방침에 추가할 내용
  - 닉네임, 한 줄, 점수 저장
  - 랭킹 공개 범위
  - 보관 기간: 별자리를 새로 채우거나 바꾸면 이전 별은 삭제, 탈퇴하면 전부 삭제
  - 만 14세 이상 조건

## 11. 남용 방지

- 친구 기기 하나당 주인 한 명의 별자리 한 회차에 한 번만 참여할 수 있다.
- 주인은 자기 링크로 참여할 수 없다(같은 기기 쿠키).
- 같은 IP에서 하루 참여 30회까지이고, 주인당 하루 새 별은 20개까지다.
- 코드 입력 시도는 같은 IP에서 1분에 10회까지다(무작위 대입 방지). 없는 코드나 막힌 코드는 같은 문구로 답한다: "코드를 다시 확인해 주세요".
- 랭킹 점수를 높이려고 여러 번 새로 채우는 것은 허용한다(재미 요소). 다만 이번 주 랭킹에는 그 주에 완성한 기록 하나만 오른다.

## 13. 테스트

- 점수 공식: 표의 조건마다 예시 쌍으로 검증한다. 경계값(55, 99)도 확인한다. 대칭성(score(A,B) = score(B,A)), 결정성(같은 입력이면 같은 점수), 시간 입력 유무와 무관함을 속성 테스트로 확인한다.
- 초대코드: 형식과 고유성, 대소문자 무시, 새로 만들면 옛 코드가 막힘, 링크와 코드가 같은 별자리로 연결, 시도 횟수 제한.
- 진행: 별자리 고르기, 칸 채우기, 완성, 다음 별자리 고르기, 완성한 별자리는 다시 못 고름, 중간에 바꾸면 별이 모두 비워지고 새 별자리 0칸부터, 새로 채우기(카드·랭킹 기록 삭제 후 0칸부터, 다른 진행 중 별자리 별도 삭제), 별 지우기 후 미완성 복귀.
- 공유 이미지: 친구 닉네임이 별 칸 수만큼 들어가고 서로 겹치지 않음, 점수·생년월일 미포함.
- 랭킹: 정렬, 동점 처리, 주 경계(KST), 비공개 설정.
- 행운 번호: 결정성, 범위, 중복 없음, 설명 문구 생성.
- 친구 생년월일이 어떤 저장소에도 남지 않는지 확인한다(저장소 호출 인자 검사).
- e2e: 주인 생성 → 양자리 고르기 → 친구 4명 참여 → 완성 → 도감 칸 누르면 양자리 랭킹 → 공유하기 → 새로 채우기.
