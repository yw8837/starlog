## Gotchas found today
- Running two gates at once corrupts both: the gate does not stop after a failed step (a failed local migration still runs e2e). Wait for one to finish.
- Local D1 migration in the gate once failed with "fetch failed" (network); rerunning it in the clone fixed it.
- Vitest "Failed to start forks worker / Timeout" while an agent and a build run: rerun with `--maxWorkers=1`; not a test failure.
- In a jsdom test, `useTestDb()` fails ("URL must be of scheme file"): mock the store instead (see `app/s/[id]/share-page.test.tsx`).
- Next route files may only export handlers: helpers go in lib (`lib/share/og.ts`).
