## 출처 미확인 목록 (보고용)
1. 반합 규칙(왕지가 들어가야 반합): 고전 근거를 못 찾았어.
2. 문창귀인 표: 고전 구절을 못 찾았어. 찾은 고전 구절(三命通會 論太極貴 "文昌貴")은 다른 표야.
3. 천간충: 고전 하나(五行大義)만 확인했어. 두 번째 독립 자료는 못 찾았어.
4. 천을귀인 庚→寅午 이본: 있다고 알려져 있지만 원문으로 확인 못 했어.
5. 세운의 입춘 경계, 야자시 정책: 고전 원문으로 확인 못 했어.
6. 淵海子平: 위키문헌판이 미완성이라 어떤 표도 확인 못 했어. 설계 A8에 적힌 "연해자평" 출처는 전부 확인 못 함이야.

## 우리 표와 다른 칸
- 관계표(육합·충·해·파·삼형·자형·삼합·방합·천간합·천간충): 원문·대조 자료와 다른 칸 **0개**.
- 신살표: 천을·학당·도화·역마·화개는 다른 칸 **0개**. 문창은 현대 자료 둘과는 0개, 三命通會 論太極貴 구절과는 대부분 달라(위 표).
