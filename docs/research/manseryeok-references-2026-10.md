# 만세력 레퍼런스 조사 — 2026-10-07

> 질문: "만세력은 저거면 되나? 다른 데는 뭐 쓰나?"
> 대상: Starlog가 쓰는 `manseryeok@2.0.0` + 정책 래퍼(`saju-policy@1`)가 국내 서비스·공개 자료의 관행과 비교해 어느 수준인가
> 방법: 앱스토어·구글 플레이 공개 설명, 공식 사이트, KASI(한국천문연구원) 공개 페이지와 2023 역서 PDF, 공공데이터포털 API 상세 페이지, GitHub 공개 API
> 엔진 11종 비교는 `saju-engine-eval.md`에 있고, 여기서는 다시 하지 않았다.
> 표기 규칙: 공개 문구로 확인하지 못한 것은 "확인 못 함"이라고 적었다. 앱 설명은 마케팅 문구라서 "적용한다"는 주장의 실제 동작은 검증하지 않았다.

## 0. 결론

- **판정: 같거나 위.** 공개 설명만으로는 우리보다 정밀하다고 확인되는 국내 서비스가 없다. 엔진을 바꿀 이유는 없다.
- **절입(節入) 정밀도:** KASI가 공표하는 단위는 **분(시·분, 한국표준시)**이다. 우리 표도 분 단위다. KASI 월력요항 기반 자료 2021–2028년 192개와 대조하니 **187개 일치, 5개는 manseryeok이 +1분**이었다. 월주를 바꾸는 절(節) 12개만 보면 94/96 일치다(§6.1).
- **우리 절입표의 원천은 KASI가 아니다.** manseryeok 패키지 헤더에 "6tail/lunar-javascript의 천문 계산값을 개발 시점에 추출"이라고 적혀 있다. KASI는 역서 범례상 NASA JPL 천체위치표로 계산한 값을 분으로 공표한다. 평가 문서의 JPL 초 단위 값 6개와 KASI 공표 분을 비교하면 **KASI = JPL의 반올림이 6/6** 일치했다.
- **경쟁 서비스가 내세우는 항목은 우리 정책과 같다.** 서머타임 자동 보정, 야자시/조자시 선택, 진태양시·경도 보정이다(포스텔러, 천을귀인, 도사폰, 낭만만세력, 음양관 등). 점신·헬로우봇·네이버 운세는 계산 방식을 공개하지 않아 비교할 수 없다.
- **부족한 건 엔진이 아니라 옵션과 UI다.** ① 연주 경계(입춘/동지) 선택 ② 윤달 '모름' 입력 ③ 출생지 세분도와 자시·진태양시 스위치 노출(§7).
- **새로 알게 된 주의점:** KASI 역서의 서머타임 표와 tzdata(manseryeok 내장표와 일치)가 1948–51년 시작 경계와 1955–60년 종료 경계에서 1시간 다르다(§6.2). 1987·1988년은 일치한다.

## 1. 조사 방법과 한계

- **소스:** 앱스토어(Apple 공개 조회 API)와 구글 플레이 상세 페이지의 설명 원문, 공식 사이트, KASI 천문우주지식정보 페이지(첫 요청으로 쿠키를 받은 뒤 열람), KASI 2023 역서 PDF, 공공데이터포털 API 상세 페이지, GitHub 공개 API.
- **로그인, 결제, 유료 API는 쓰지 않았다.** 같은 사이트에 연속으로 보낸 요청은 1.5~3초 간격을 뒀다.
- **파일:** 읽기용으로 KASI 2023 역서 PDF(27MB) 1개를 임시 폴더에 받았다. KASI의 "24기 데이터 다운받기" 파일 같은 그 밖의 파일은 받지 않았다(헤더 요청은 HTTP 403).
- **접근하지 못한 곳:**
  - `fortune.naver.com`: WebFetch 차단, 브라우저 창 차단, curl 연결 실패, insane-search 소진
  - 공공데이터포털 OpenAPI의 실제 응답(서비스 키 필요)
  - 2020년 이후 월력요항 관보 원문(KASI는 전자관보 링크만 제공)
  - 포스텔러 만세력 Pro 웹앱(자바스크립트 전용이라 본문 없음)

1. KASI 표를 그대로 쓰는 곳: 원광만세력, DHcommunication 만세력, 술술만세력, 인쇄본
2. 자체 천문 계산: 정해 만세력(주장), 만세력 TAU, 음양관(KASI + JPL 병용)
3. 방식을 공개하지 않는 곳: 점신, 헬로우봇, 네이버, 사주나루, 포스텔러(옵션만 공개)

## 3. KASI 1차 자료: 절입의 기준과 정밀도

- **역서 범례(2023 역서 p.2):** "역서에 기재된 시각은 특별한 언급이 없다면 한국 표준자오선(동경 135˚)을 기준으로 한 한국 표준시(KST=UTC+9h)"이고, 해·달·행성 위치는 NASA JPL 천체위치표로 계산했다. KASI가 올해로 48번째 발행한다고 적혀 있다.
- **24기 표(p.8, 문서 이미지로 확인):** 태양황경(도) / 한국표준시 일자(월, 일) / 시각(시, 분). 예: 2023 입춘 2월 4일 11시 43분, 청명 4월 5일 10시 13분. **분 단위다.**
- **서머타임 표(p.212, 이미지로 확인):** 1948–51, 1955–60, 1987–88년의 시작·종료가 시 단위로 있다. 24기 표에는 반영되어 있지 않다. 표준자오선 표(p.211)는 1908.4.1–1911.12.31 동경 127°30′, 1912.1.1–1954.3.20 동경 135°, 1954.3.21–1961.8.9 동경 127°30′, 1961.8.10– 동경 135°다. 이는 `saju-policy@1`의 P1과 같다.
- **월력요항:** KASI 안내문에 "2019년까지는 한국천문연구원이 발표했으며, 2020년부터 과학기술정보통신부, 2024년부터는 우주항공청이 매년 관보에 게재하여 발표"한다고 적혀 있다. 보도자료는 "천문법에 따라 매년 발표"라고 한다.
- **달력자료 페이지(2021–2028):** 연도별 24절기를 월·일·시·분으로 보여 준다. "이 자료는 공식 발표 자료가 아닙니다. 공식 발표 자료는 월력요항을 확인해주시기 바랍니다"라는 면책 문구가 있다. 안내문은 2년 뒤(현재 2028년) 자료를 "월력요항이 공식발표되기 전의 자료"라고 밝힌다. 2027년은 월력요항 탭에 관보 링크가 올라와 있다(원문 대조는 못 함).
- **KASI의 24기 데이터 파일:** 역서 페이지(`/kor/almanac/pageView/26`)에 "24기 데이터 다운받기" 링크(`/kor/almanac/solarTerms/download`)가 있다. 내용과 형식은 확인 못 함(받지 않았다).
- **OpenAPI(공공데이터포털):** 24절기 오퍼레이션 `get24DivisionsInfo`. 문서 표에 `kst` "한국표준시각"(샘플 `0120`)과 `sunLongitude`(샘플 285)가 있다. 이용허락범위 제한 없음, 활용신청 필요(개발·운영 모두 자동승인), 개발계정 일 10,000건이다. 서비스 키가 없어 실제 응답은 못 봤다.
- **음양력 변환기:** 양력 입력 범위가 −59년 2월 13일 ~ **2050년 12월 31일**이다. 음력 입력은 "평달 / 윤달 / 평달인지 윤달인지 알지 못함" 3택이다. manseryeok도 2050년 이후 음력은 KASI 미제공이라 6tail 계산이라고 밝힌다(`dist/calendar/lunar-data.js` 헤더).
- **표준시 법적 근거:** 표준시에 관한 법률이 동경 135도 자오선을 표준자오선으로 정한다(법령 문구는 elaw.klri.re.kr에서 확인).
- **KASI 공표 분은 반올림 값이다.** 평가 문서 §4.1의 JPL 초 단위 값 6개와 KASI 공표값을 나란히 놓으면 전부 가장 가까운 분이다.

  | 절기 | JPL (평가 문서) | KASI 공표 |
  |---|---|---|
  | 2023 입춘 | 11:42:34 | 11:43 |
  | 2023 청명 | 10:13:04 | 10:13 |
  | 2024 입춘 | 17:27:08 | 17:27 |
  | 2024 경칩 | 11:22:47 | 11:23 |
  | 2026 백로 | 23:41:18 | 23:41 |
  | 2026 한로 | 15:29:18 | 15:29 |

- **서머타임과 24기:** 1987년 망종은 KASI 자료상 6월 6일 14시 19분(KST)이다. 이 값에 서머타임(+1시간)을 더하지 않는다는 것은 위키독스(남두성의 음양 만세력)가 옛 KASI 질의응답을 인용한 내용이다. 원 게시물은 삭제되어 1차 확인은 못 했다. 역서 범례의 "KST(UTC+9h) 기준 표기"와는 모순되지 않는다.

## 6. 새로 측정한 두 가지

### 6.1 manseryeok 절입표 vs KASI 공표값 (2021–2028, 192개)

**방법:**
1. KASI 달력자료 페이지에서 연도별 24절기 월·일·시·분을 읽었다: `GET https://astro.kasi.re.kr/kor/life/post/calendarData?search_year=YYYY` (홈에서 받은 쿠키 사용).
2. `manseryeok.getSolarTermsOfYear(year)`의 `date`(UTC)에 9시간을 더해 KST로 바꿨다. 비교 기간에는 서머타임이 없다.
3. 2023년은 같은 KASI의 2023 역서 PDF 24기 표와도 24/24 일치해 두 자료가 같음을 확인했다.

**결과:** 192개 중 **187개 일치(97.4%)**. 불일치 5개는 모두 manseryeok이 1분 늦다.

| 구분 | 일치 |
|---|---|
| 절(節) 12개 — 월주를 바꾸는 절기 | 94/96 |
| 중기(中氣) 12개 — 월주에 영향 없음 | 93/96 |

| 연도 | 절기 | KASI | manseryeok | 월주 영향 |
|---|---|---|---|---|
| 2022 | 입동 | 11-07 19:45 | 19:46 | 절: 1분 창에서만 월주가 갈림 |
| 2022 | 소설 | 11-22 17:20 | 17:21 | 중기: 없음 |
| 2024 | 소설 | 11-22 04:56 | 04:57 | 중기: 없음 |
| 2027 | 청명 | 04-05 09:17 | 09:18 | 절: 1분 창에서만 월주가 갈림 |
| 2028 | 곡우 | 04-19 22:09 | 22:10 | 중기: 없음 (2028은 KASI 사전 자료) |

**해석:** 불일치는 전부 ±1분 안이고, 평가 문서의 P2(절입 ±120초 경계 경고)가 흡수하는 범위다. manseryeok README의 "KASI와 분 단위 일치 검증"은 엄밀히는 97.4%다. 2020년 이전 연도와 KASI 월력요항 관보 원문 대조는 못 했다.

### 6.2 KASI 역서의 서머타임 표 vs tzdata (Node 25.9 ICU, tzdata 2026a)

KASI 표의 시각은 전환 직전 벽시계 기준(1987년 "5월 10일 2시"는 02:00에서 03:00으로 바뀐 순간)으로 읽었다. tzdata 쪽은 `Asia/Seoul`의 전환 시점을 ICU로 직접 스캔했다. manseryeok 내장표는 평가 문서에서 tzdata와 일치 확인했다.

| 연도 | KASI 시작 | tzdata 시작 | KASI 종료 | tzdata 종료 |
|---|---|---|---|---|
| 1948 | 5/31 23시 | 5/31 24시 | 9/12 24시 | 9/12 24시 (일치) |
| 1949 | 4/2 23시 | 4/2 24시 | 9/10 24시 | 9/10 24시 (일치) |
| 1950 | 3/31 23시 | 3/31 24시 | 9/9 24시 | 9/9 24시 (일치) |
| 1951 | 5/6 23시 | 5/5 24시 | 9/8 24시 | 9/8 24시 (일치) |
| 1955 | 5/5 0시 (일치) | 5/5 0시 | 9/9 1시 | 9/9 0시 |
| 1956 | 5/20 0시 (일치) | 5/20 0시 | 9/30 1시 | 9/30 0시 |
| 1957 | 5/5 0시 (일치) | 5/5 0시 | 9/22 1시 | 9/22 0시 |
| 1958 | 5/4 0시 (일치) | 5/4 0시 | 9/21 1시 | 9/21 0시 |
| 1959 | 5/3 0시 (일치) | 5/3 0시 | 9/20 1시 | 9/20 0시 |
| 1960 | 5/1 0시 (일치) | 5/1 0시 | 9/18 1시 | 9/18 0시 |

- **차이:** 1948–51년 시작은 KASI가 1시간 이르고(1951년은 23시간 늦음), 1955–60년 종료는 KASI가 1시간 늦다.
- **영향:** 해당 경계 전후 1시간에 태어난 사람만 달라진다. 1987·1988년은 일치한다.
- **어느 쪽이 맞는지는 확인 못 함.** 현재 P1은 tzdata를 따른다.

## 8. 판정

- **같거나 위.** 경쟁 서비스 중 설명으로 확인되는 항목(서머타임 자동, 경도 보정, 야자시/조자시 선택)은 우리 정책 P1~P4가 모두 포함한다.
- 절입 정밀도는 KASI 공표 정밀도(분)와 같다. 일치율은 2021–2028 기준 97.4%이고, 차이는 ±1분이다.
- 우리가 더 나은 점(공개 설명에서 확인되는 범위): 서머타임·표준시 연혁을 tzdata와 대조했고, 없는·겹치는 시각을 따로 처리하며(P8), 시간 모름에서 월주 경계 모호성까지 표시한다(P6). 시간 모름 처리가 설명에서 확인된 서비스는 원광만세력(시간 간지 공백)과 사주어때뿐이고, 둘 다 월주 경계 모호성 표시는 언급이 없다.
- 낮은 점: 입춘/동지 연주 경계 선택이 없다(§7-1).
- **비교 한계:** 점신, 헬로우봇, 네이버 운세는 방식이 비공개라 "그들보다 낫다"고 말할 수 없다.
- **후속 제안(코드 수정 아님):** KASI 월력요항 2021–2028의 24절기 192개(허용 ±1분)를 골든 테스트에 추가하면 manseryeok 업데이트 때 회귀를 잡을 수 있다. 값은 위 URL에서 키 없이 읽을 수 있다.

## 9. 확인 못 한 것

- 점신, 헬로우봇, 사주나루, 사주월드, 네이버 운세: 절입 출처·정밀도, 서머타임, 경도, 자시, 시간 모름, 윤달 전부 확인 못 함 (공개 설명 없음 또는 접근 차단)

- 천을귀인, 8자어때, 낭만만세력, 도사폰, 나이스 만세력, 음양관, 술술만세력: 절입 단위(분/초), 시간 모름, 윤달
- KASI 24절기 공식 전체값: OpenAPI 실제 응답(키 필요), "24기 데이터 다운받기" 파일(받지 않음), 2020년 이후 월력요항 관보 원문. 2021–2028은 KASI 달력자료 페이지(비공식 면책 문구 포함)로만 확인했고, 2020년 이전 연도의 manseryeok 대 KASI는 확인 못 함
- 1954–61년(UTC+8:30 시기) KASI 24기 표기 기준(UTC+9인지 당시 표준시인지)
- KASI가 24기에 서머타임을 반영하지 않는다는 옛 답변의 원문 (위키독스 인용만 확인)
- 인쇄본 만세력의 절입 인쇄 단위, 자시 규칙, 경도 규칙 (본문 미열람)
- §6.2 서머타임 표 불일치에서 KASI와 tzdata 중 어느 쪽이 사실에 맞는지
- sajupy `calendar_data.csv`의 출처, korean-saju의 KASI 임베드·검증 수치 (자체 주장)
