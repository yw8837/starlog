# "타로"·"사주" 검색 1페이지 계획 (2026-10-08)

운영자 요청은 "타로나 사주로 검색하면 1페이지 안에 들었으면 좋겠다"예요. 이 문서는 오늘 실측한 검색 결과와 경쟁 사이트 구조를 근거로, 거기까지 가는 순서를 정리해요. 감사 문서 `docs/seo/audit-2026-10-08.md`(72.6점)의 후속이에요.

## 요약

1. **지금 색인은 0건이에요.** 구글·네이버·빙 모두 `site:` 결과가 없어요. 오늘 서치콘솔 등록, 사이트맵 제출, 색인 요청 2건을 했으니 며칠 안에 들어가기 시작해야 해요.
2. **구글의 "타로", "사주", "무료 타로", "무료 사주" 1페이지는 바로 해 보는 도구 페이지 차지예요.** 정보 글인 우리 가이드는 이 검색어의 의도와 달라요. 이 검색어는 앱의 도구 페이지(`/now`, `/today`, `/tarot/new`, `/saju/new`)가 맡아야 하는데, 지금 그 페이지들은 서버에서 보이는 글이 113~358자이고 H1에 "타로"나 "사주"가 없어요.
3. **1페이지 도구 사이트는 오래됐거나, 글이 많거나, 새로 왔어도 본문과 링크가 충실해요.** 카니타로는 사이트맵이 4개뿐인데 "타로" 3위예요(설명문에 2017년부터 운영). 타로탭은 웨이백 첫 수집이 2024-06인데 "무료 타로" 2위, "AI 타로" 1위예요.
4. **네이버는 웹사이트보다 블로그·카페·지식iN·클립을 먼저 보여 줘요.** 네이버 1페이지는 서치어드바이저 등록만으로는 어렵고, 블로그 글이 같이 있어야 한다고 봐요(검색 결과 구성에서 한 추론이에요).
5. **그래서 순서는 색인 → 롱테일(카드 뜻·사주 용어) → 미들(무료 타로, AI 사주, 카드 78장) → 헤드(타로, 사주)예요.** 헤드 검색어 1페이지는 몇 달 단위 목표로 잡는 게 정직해요.

## 3. 읽은 것

1. **헤드·미들 검색어는 도구 의도예요.** "타로/사주/무료 X/AI X" 1페이지 대부분이 입력하고 바로 결과를 보는 페이지예요. 위키·나무위키 두 자리만 정보 페이지예요. 우리 가이드 허브로 이 검색어를 노리면 의도가 어긋나요.
2. **도구 페이지는 본문이 적어도 뜰 수 있지만, 그건 나이와 외부 언급 덕이에요.** 카니타로(362자)는 오래 운영했고 네이버 블로그가 링크를 걸어요. 새 사이트인 타로탭은 본문 3,521자, "어떻게 작동하나요", FAQ, 내부 링크 57개로 들어갔어요. 우리는 새 도메인이라 타로탭 쪽 길이 맞아요.
3. **카드 뜻·일주 같은 정보 검색어는 블로그와 사전형 사이트 차지예요.** 78장 목록 페이지(ezracard, fatemaster)와 일주 사전(두루미사주)이 들어가요. 우리 카드 글은 메이저 22장뿐이라 "타로 카드 의미"류에서 목록 페이지를 만들 재료가 모자라요.
4. **"AI 사주", "AI 타로"는 새 서비스들이 이미 1페이지에 있어요.** 사주핑, SajuGPT, 호리 AI, 타로탭이 여기 있어요. 모음 페이지(sajuai.io "AI 사주 추천 50선")와 개발 커뮤니티 소개글(GeekNews)도 1페이지에 있어요. 등록·소개만으로 링크와 유입을 얻을 수 있는 자리예요. 약관에 "AI가 생성하는 타로·사주"라고 이미 밝히고 있어서, 이 검색어를 노려도 표시 원칙과 어긋나지 않아요(모델·회사 이름은 계속 쓰지 않아요).
5. **브랜드 검색이 안 잡혀요.** "스타로그 타로"는 별(The Star) 카드 글이 차지해요. 이름이 일반 단어와 겹치니 "스타로그 타로", "스타로그 사주"처럼 둘을 묶은 표현을 일관되게 써야 해요.

- 구글 스팸 정책의 "대량 생성 콘텐츠 악용"에 걸리지 않게, 한 틀에 이름만 바꿔 찍는 글은 쓰지 않아요. 글마다 사람이 검수해요.

### D. 외부 언급(운영자)

- 네이버 블로그: 운영자 블로그에 카드 뜻·사용 후기 글을 쓰고, 테스터 후기에는 도구 링크를 걸어요. 대가를 준 후기는 "광고·협찬" 표시가 필요해요(공정위 추천·보증 심사지침).
- AI 사주·타로 모음 사이트 등록(예: sajuai.io), 개발 커뮤니티 소개글(GeekNews "Show" 형식).
- Threads·인스타 글의 링크를 앱 홈 대신 해당 도구나 가이드 글로 걸어요.
- **하지 말 것:** 지식iN 홍보 답변, 링크 구매, 자동 생성 글 대량 발행.

## 6. 측정

- 매주 월요일: 서치콘솔 실적(검색어별 노출·클릭·평균 순위)과 페이지 색인 수, 네이버 서치어드바이저 수집 현황, `site:` 결과 수.
- 4주 뒤(11월 첫 주): 이 문서의 단계표를 실제 숫자로 다시 써요. 수요는 서치콘솔 검색어 보고서로 확인해요(이번 문서는 검색량 데이터 없이 썼어요).

## 측정 방법과 한계

- 구글 결과는 앱 브라우저에서 `https://www.google.com/search?q=…&hl=ko&gl=kr`을 열어 일반 결과 링크만 뽑았어요. 개인화·위치에 따라 순서가 달라질 수 있어요.
- 네이버 결과는 `search.naver.com` HTML을 curl로 받아 섹션 제목과 링크를 뽑았어요(앱 브라우저는 네이버 검색을 막아요).
- 웨이백 첫 수집일은 도메인 나이의 하한 근거일 뿐이에요. 검색량, 백링크 수는 데이터가 없어 다루지 않았어요.
